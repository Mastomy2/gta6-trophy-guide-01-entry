Leonida Trophy Guide — an offline guide and tracker for all 55 GTA VI PlayStation 5 trophies
(1 platinum, 2 gold, 6 silver, 46 bronze). Every trophy shows its official name, description and grade,
plus a guide written in our own words with its sources named beside it. A 5-stage roadmap leads to the
platinum (~200 hours, difficulty 4/10 per PowerPyx), the one potentially missable trophy
(Positive Mental Attitude — the Chapter 1 meditation) is flagged, and the tracker saves progress in the
browser with export/import, kind filters (story, missable, collectibles, activities, online) and a
spoiler-safe mode that hides story trophies until earned.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

No build step, no network at runtime — the app loads only files from `app/`.

## Sources

- Trophy names, descriptions and grades: the PlayStation trophy list as published via Exophase / PSNProfiles.
- Methods, counts and roadmap: PowerPyx — GTA 6 Trophy Guide & Roadmap
  (https://www.powerpyx.com/gta-6-grand-theft-auto-vi-trophy-guide-roadmap/), with GTABase where noted.
- Every guide is written in our own words; sources are cited per trophy, never copied.

Unofficial fan guide, not affiliated with Rockstar Games, Sony or PlayStation. No Rockstar artwork or logos are used.
